📚 Online Exam Portal (Frontend)

A responsive and interactive Online Exam Portal built using modern frontend technologies. It provides a smooth interface for students to attempt exams, view results, and track performance.

🚀 Features
📝 Multiple Choice Questions (MCQs)
⏱️ Timer-based exams
📊 Instant result calculation
🎯 Score display & performance tracking
📱 Fully responsive design
🎨 Clean and modern UI
🛠️ Tech Stack
HTML5
CSS3
JavaScript
📂 Project Structure
/project-folder
│── index.html
│── exam.html
│── result.html
│── style.css
│── script.js
│── questions.json
⚙️ How to Run
Download or clone the repository
Open index.html in your browser
Start the exam and test your knowledge
